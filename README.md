#Проект интернет-магазина товаров

##Описание: создано приложение catalog на основе фреймворка Django:
1. Данное приложение зарегистрировано в настройках (config\settings.py\installed app)
2. Для него настроена маршрутизация в файле catalog\urls
3. Реализованы контроллеры
4. Для работы в проекте поделючена БД postgres
5. В приложении catalog созданы две модели Category и Product
6. Созданы и применены миграции для моделей
7. Модели зарегистрированы в админке
8. Сформированы фикстуры для моделей
9. Создана кастомная команда в management/commands/test_product.py
10. Создана главная страница приложения, на которой представлен перечень товаров. Чтобы подробнее рассмотреть товар, необходимо нажать на кнопку "Подробнее".
11. Создан базовый шаблон с одинаковыми колонтитулами для всех страниц приложения

##Установка:
1. Клонируйте репозиторий git@github.com:Ekaterina-RA/DjangoProject.git
2. Установите зависимости pip install
